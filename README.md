# PlavioHD for CloudStream

PlavioHD inside CloudStream — movies and series, many sources, subtitles included.

## The main plugin

**PlavioHD** — all sources in one plugin, with the source and quality pickers in its settings. Start here if you just want everything.

## One plugin per source

Prefer it light? There is also one small plugin per source, named after the source itself — e.g. `4KHDHub`, `MoviesBazar` or `SoraStream` — most with the source's own logo. Install only the sources you actually use; each plugin carries just its own source, with the quality picker in its settings.

If you have your own configured PlavioHD link, paste it in the plugin settings — a filled link always wins, in every plugin. Clear it and the plugin goes back to its own source.
