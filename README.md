# PlavioHD for CloudStream

PlavioHD inside CloudStream — movies and series, many sources, subtitles included.

## Two ways to install

- **PlavioHD** — the all-in-one plugin: every PlavioHD source in a single install. Its settings have pickers for sources and qualities, so you can tick exactly what you want without visiting the configure page.
- **PlavioHD-\<source\>** — one small plugin per source, e.g. `PlavioHD-4KHDHub`, `PlavioHD-MoviesBazar` or `PlavioHD-SoraStream`. Install only the sources you actually use; each one carries just its own source, with the quality picker still in its settings.

Both ways give the same streams, filed under their real source names.

If you have your own configured PlavioHD link, paste it in the plugin settings — a filled link always wins, in every plugin. Clear it and the plugin goes back to its own sources.
